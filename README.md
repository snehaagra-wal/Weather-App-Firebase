# weather-dashboard
# 🌤️ Modern Weather Dashboard

A sleek and responsive Weather Dashboard built using *HTML, CSS, and JavaScript. This project fetches real-time weather data and securely stores search history in **Firebase Firestore*.

## 💡 Motivation
I was really excited to try out *Firebase* and see how it works in a real project. I decided to build this basic weather dashboard to learn how to integrate a backend database with a frontend application and handle real-time API data.

## 🚀 Features
•⁠  ⁠*Real-time Data:* Fetches live temperature and weather conditions using the OpenWeatherMap API.
•⁠  ⁠*Glassmorphism UI:* Modern design featuring a blurred background effect (⁠ backdrop-filter ⁠) and elegant linear gradients.
•⁠  ⁠*Database Integration:* Automatically saves every searched city and its temperature to *Firebase Firestore* for history tracking.
•⁠  ⁠*Responsive Design:* Optimized for a smooth viewing experience on both desktop and mobile screens.

## 🛠️ Tech Stack
•⁠  ⁠*Frontend:* HTML5, CSS3 (Flexbox, Glassmorphism), JavaScript (ES6+)
•⁠  ⁠*Backend/Database:* Firebase Firestore (Compat Version)
•⁠  ⁠*API:* OpenWeatherMap API

## 📸 Preview
The app features a central glass-styled card, a large circular interactive search button, and dynamic weather updates that reflect the searched city's data instantly.

## ⚙️ How to Use
1.⁠ ⁠Clone this repository to your local machine.
2.⁠ ⁠Open ⁠ index.html ⁠ in your browser (using VS Code Live Server is recommended).
3.⁠ ⁠Type any city name (e.g., Jabalpur, Singrauli) in the search box.
4.⁠ ⁠Click the *Circular Search Button*.
5.⁠ ⁠The current temperature and weather description will appear on the screen.
6.⁠ ⁠Check your Firebase Console to see the search history being saved in real-time!

## 🔧 Setup Instructions
To run this project with your own credentials:
1.⁠ ⁠Replace the ⁠ firebaseConfig ⁠ object in ⁠ script.js ⁠ with your own Firebase project settings.
2.⁠ ⁠Replace ⁠ weatherApiKey ⁠ with your unique API key from OpenWeatherMap.
